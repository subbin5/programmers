# 🧩 프로그래머스 풀이

[프로그래머스 코딩테스트 연습](https://school.programmers.co.kr/learn/challenges)에서 푼 문제를 모아 두는 저장소입니다.

## 📁 구조

정답을 제출하면 [BaekjoonHub](https://github.com/BaekjoonHub/BaekjoonHub) 확장 프로그램이 자동으로 커밋합니다.

```
프로그래머스/
├── 0/   ← Lv.0
├── 1/   ← Lv.1
├── 2/   ← Lv.2
└── 3/   ← Lv.3
    └── 문제번호. 문제이름/
        ├── README.md   ← 문제 정보, 성능 요약, 제출 일자
        └── 풀이 코드
```

## ✍️ 정리 방식

- **코드**: 이 저장소 (자동 업로드)
- **생각**: 접근 방법, 막혔던 점, 시간복잡도, 배운 점은 개인 노트에 따로 정리합니다.
- 막혔던 문제는 다시 풀어 보고, 더 나은 풀이를 찾으면 새로 커밋합니다.

## 📌 원칙

- 문제 본문은 옮기지 않고 링크만 남깁니다. 문제의 저작권은 프로그래머스에 있습니다.
- 풀이는 스스로 이해한 것만 올립니다.
